Source status
Updated every morning by GitHub Actions. Titles are matched by keywords, so some off-topic postings appear on purpose. “Graduates?” is read from the job description: graduates = explicitly open to graduates (or a PhD / graduate programme / research post), students = asks for current enrolment (convention de stage, Pflichtpraktikum, “currently enrolled”…), unclear = nothing found. Hover the label to see the phrase it was based on, and always check the posting. Dashed topic tags come from the description only. “Posted” is the publication date given by the career site; “seen …” means the site gives no date and it is the day the tracker first found the posting. The page reloads the data by itself when a new update is published.
